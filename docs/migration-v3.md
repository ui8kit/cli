# Migration: ui8kit 2.x → 3.x

ui8kit 3.x targets `@ui8kit/registry@3`, a **per-runtime** registry generated by ui8kit codegen 3. The config contract (`contractVersion: "2.0.0"`) is unchanged; existing `ui8kit.config.json` files keep working.

## What changed

| Area | 2.x | 3.x |
|------|-----|-----|
| Registry layout | one `r/` with multi-stack items | `r/<runtime>/` — `react`, `vue`, `svelte`, `solid`, `webcomponent` |
| Default registry version | `@latest` | CLI major (`@ui8kit/registry@3`); pin with `--registry-version 3.0.0` |
| Brick install folder | `{dir}/components/ui/<brick>/` | `{dir}/ui/<brick>/` (item targets `ui/<brick>/…`) |
| Agent rules | — | `registry:rules` → `.cursor/rules/ui8kit-primitives.mdc`, installed by `init` |
| Web Components | — | `--framework webcomponent` (`*.wc.ts` + shared files) |
| Empty folders | `init` scaffolded all kit folders | only folders of written files are created |
| Fallback CDN | raw GitHub | removed (unpkg / jsDelivr only) |
| Config `$schema` | `ui.buildy.tw` | `https://cdn.jsdelivr.net/npm/@ui8kit/registry@3/schema/schema.json` |
| `--import-style package` | supported | deprecated (warns) |

## Upgrade steps (React / Vue / Svelte / Solid)

1. Update the runner: `npx ui8kit@3 …` (or `npm i -D ui8kit@3`).
2. Remove a pinned `"registryVersion": "2.0.0"` (or set `"3.0.0"`) and any `registryUrl` pointing at the old flat `r/`.
3. Re-run init to get the agent rules: `npx ui8kit@3 init --yes --framework react --dir src` (it rewrites `ui8kit.config.json` — keep a copy of custom `paths` / `aliases`).
4. Re-install bricks: `npx ui8kit@3 add <names…> --force`. They land in `{dir}/ui/`; move your imports from `components/ui/…` to `ui/…`, or keep the old folder with `"paths": { "ui": "components/ui" }`.
5. Delete the old `{dir}/components/ui/` copies once nothing imports them.

## Legacy stacks (templ, latte, twig, jinja2)

They are not in the 3.x registry. Stay on the frozen 2.0 digest:

```bash
npx ui8kit@3 init --yes --framework templ --dir internal --registry-version 2.0.0
npx ui8kit@3 add button --runtime templ --registry-version 2.0.0
```

or set `"registryVersion": "2.0.0"` in `ui8kit.config.json`.
